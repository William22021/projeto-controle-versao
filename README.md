# Projeto Controle de Versão

## Objetivo
Demonstrar a utilização de ferramentas de controle de versão e documentação de software.

## Ferramentas utilizadas
- Git
- GitHub
- GitHub Desktop
- Visual Studio Code
- Inteligência artificial generativa

## Descrição
Este projeto apresenta a criação de um repositório, a edição de arquivos e o registro de alterações utilizando o Git e o GitHub.

## Atividade prática
Será criado e editado um arquivo HTML no Visual Studio Code. As alterações serão analisadas no GitHub Desktop e registradas utilizando o padrão Conventional Commits, com apoio de inteligência artificial.

## Conventional Commits
- `feat`: nova funcionalidade.
- `fix`: correção de erro.
- `docs`: alteração na documentação.
- `refactor`: reorganização do código.
- `test`: criação ou alteração de testes.
